Kumade

外部への送信の公表

日本の利用者向けの公表です。

Kumade が、利用者の端末から外部へ送る情報と、その送り先です。どの送信も、送る前に確認の画面を出し、利用者が許可したときだけ、その 1 回を送ります。許可は Kumade の 設定 › 許可した送信 から、いつでも取り消せます。取り消す前に送ったものには影響しません。

調べる URL に、病歴などの機微な情報を含めないでください。

配信の委託先

次の事業者は、送り先の配信を受け持ち、端末の IP アドレスが伝わります。Kumade の送り先ではありません。

  • Amazon Web Services（アメリカ合衆国）: Common Crawl の索引と保存記録、Hugging Face のファイルの配信。Hugging Face の配信は、アメリカ合衆国以外の国の基盤を通ることがあります。
  • Cloudflare・Fastly・Gcore などの CDN（アメリカ合衆国などの会社）: jsDelivr の配信（jsDelivr の委託先）。

いま送っていないもの

URL を指定したページの取得とクロール（capture service）と、Yataverse からのファイルの取得は、送り先の運営者が確定していないため、宣言しておらず、送りません。
